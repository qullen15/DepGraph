# DepGraph

Инструмент визуализации графа зависимостей для менеджера пакетов pip.

## Общее описание

DepGraph анализирует зависимости Python-пакетов (pip), строит граф
зависимостей с учётом транзитивности и визуализирует его.
Приложение реализовано в форме CLI и настраивается опциями
командной строки.

Текущий статус: завершены этапы 1-3.

## Описание функций и настроек

### Параметры командной строки

| Параметр | Назначение | Обязательность |
| --- | --- | --- |
| `--package NAME` | имя анализируемого пакета | обязательный |
| `--repo URL\|PATH` | URL репозитория или путь к файлу тестового репозитория | обязательный |
| `--test-mode` | режим работы с тестовым репозиторием | флаг |
| `--version VER` | версия пакета | обязательна в реальном режиме |
| `--ascii-tree` | вывод зависимостей в формате ASCII-дерева | флаг |
| `-h`, `--help` | справка по параметрам | — |

При запуске приложение выводит все параметры в формате ключ-значение.

### Обработка ошибок

- некорректное имя пакета — ошибка;
- некорректный формат версии — ошибка;
- реальный режим без `--version` — ошибка;
- в реальном режиме `--repo` должен быть URL (http/https);
- в тестовом режиме `--repo` должен быть существующим файлом;
- неизвестные параметры и значения у флагов — ошибка argparse.

При ошибке сообщение печатается в stderr, код завершения 1;
при успехе код завершения 0.

### Сбор данных (этап 2)

Метаданные пакета загружаются напрямую из PyPI по адресу
`<repo>/pypi/<имя>/<версия>/json` стандартной библиотекой `urllib`
(без pip и сторонних библиотек). Прямые зависимости берутся из поля
`info.requires_dist` (строки формата PEP 508).

Допущения:
- зависимости с маркером `extra == "..."` (опциональные дополнения)
  не учитываются как прямые;
- маркеры окружения (`python_version<...`) отбрасываются, сама
  зависимость учитывается;
- спецификатор версии выводится как есть; выбор конкретной версии
  зависимого пакета появится на этапе 3.

При ошибке загрузки (404, нет соединения, некорректный JSON)
сообщение печатается в stderr, код завершения 1.

### Граф зависимостей (этап 3)

Граф строится алгоритмом **DFS с рекурсией** (`build_graph`): от корневого
пакета рекурсивно обходятся все зависимости, включая транзитивные.
Граф хранится в памяти как словарь смежности `{пакет: [зависимости]}`.

Циклические зависимости обрабатываются корректно: множество `visited`
не позволяет войти в узел повторно, поэтому обход всегда завершается.
Дополнительно `find_cycle` (DFS со стеком пути) находит цикл и выводит
сообщение вида `Обнаружен цикл: A -> B -> D -> A`.

Допущение: зависимости корневого пакета берутся для заданной версии,
а для транзитивных пакетов — для последней доступной версии.

### Тестовый режим

Вместо URL репозитория указывается путь к файлу описания графа
(`--test-mode`). Формат файла — по одной строке на пакет:

```text
ИМЯ: ЗАВИСИМОСТЬ1 ЗАВИСИМОСТЬ2
```

Имена пакетов — заглавные латинские буквы. Пустые строки пропускаются.
Пример файла:

```text
A: B C
B: D
C: D
D:
```

Ошибки тестового режима: файл не найден, строка без `:`, имя не из
заглавных букв, анализируемый пакет отсутствует в графе. Во всех случаях
сообщение печатается в stderr, код завершения 1.

## Сборка и запуск тестов

Сборка не требуется: проект написан на Python и запускается без компиляции.

Запуск (из корня репозитория):

- Linux / macOS: `./run.sh` или `python3 src/main.py`
- Windows: `run.bat` или `py src/main.py`

Запуск тестов (из корня репозитория):

- Linux / macOS: `python3 -m pytest tests/ -v`
- Windows: `py -m pytest tests/ -v`

Демонстрация параметров и ошибок (Windows): `./check_config.bat`
Демонстрация графа и циклов (Windows): `./check_graph.bat`

## Примеры использования

Корректный запуск:

```text
$ py src/main.py --package requests --repo https://pypi.org/pypi --version 2.31.0
package: requests
repo: https://pypi.org/pypi
test-mode: выключен
version: 2.31.0
ascii-tree: выключен
```

Ошибка параметра:

```text
$ py src/main.py --package requests --repo https://pypi.org/pypi
Ошибка: в реальном режиме требуется параметр --version
```

Тестовый режим (ромб):

```text
$ py src/main.py --package A --repo tests/data/graph.txt --test-mode
A: B C
B: D
C: D
D:
```

Тестовый режим (цикл):

```text
$ py src/main.py --package A --repo tests/data/cycle.txt --test-mode
A: B
B: D
D: A
Обнаружен цикл: A -> B -> D -> A
```

Ошибка формата:

```text
$ py src/main.py --package A --repo tests/data/bad.txt --test-mode
Ошибка: строка 1: имя не заглавные буквы: a
```

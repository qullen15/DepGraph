# DepGraph

Инструмент визуализации графа зависимостей для менеджера пакетов pip.

## Общее описание

DepGraph анализирует зависимости Python-пакетов (pip), строит граф
зависимостей с учётом транзитивности и визуализирует его.
Приложение реализовано в форме CLI и настраивается опциями
командной строки.

Текущий статус: завершены все 5 этапов

## Описание функций и настроек

### Параметры командной строки

| Параметр | Назначение | Обязательность |
| --- | --- | --- |
| `--package NAME` | имя анализируемого пакета | обязательный |
| `--repo URL\|PATH` | URL репозитория или путь к файлу тестового репозитория | обязательный |
| `--test-mode` | режим работы с тестовым репозиторием | флаг |
| `--version VER` | версия пакета | обязательна в реальном режиме |
| `--ascii-tree` | вывод зависимостей в формате ASCII-дерева | флаг |
| `--reverse` | вывод обратных зависимостей (только с `--test-mode`) | флаг |
| `-h`, `--help` | справка по параметрам | — |

При запуске приложение выводит все параметры в формате ключ-значение.

### Обработка ошибок

- некорректное имя пакета — ошибка;
- некорректный формат версии — ошибка;
- реальный режим без `--version` — ошибка;
- в реальном режиме `--repo` должен быть URL (http/https);
- в тестовом режиме `--repo` должен быть существующим файлом;
- режим `--reverse` без `--test-mode` — ошибка;
- неизвестные параметры и значения у флагов — ошибка argparse (код 2);
- ошибки загрузки метаданных (404, нет соединения, некорректный JSON);
- отсутствие Graphviz — ошибка рендера.

При ошибке сообщение печатается в stderr, код завершения 1;
при успехе код завершения 0.

### Сбор данных (этап 2)

Метаданные пакета загружаются напрямую из PyPI по адресу
`<repo>/pypi/<имя>/<версия>/json` стандартной библиотекой `urllib`
(без pip и сторонних библиотек). Прямые зависимости берутся из поля
`info.requires_dist` (строки формата PEP 508).

Допущения:
- зависимости с маркером `extra == "..."` (опциональные дополнения)
  не учитываются как прямые;
- маркеры окружения (`python_version<...`, `platform_system==...`)
  отбрасываются, сама зависимость учитывается;
- спецификатор версии выводится как есть.

### Граф зависимостей (этап 3)

Граф строится алгоритмом **DFS с рекурсией** (`build_graph`): от корневого
пакета рекурсивно обходятся все зависимости, включая транзитивные.
Граф хранится в памяти как словарь смежности `{пакет: [зависимости]}`.

Циклические зависимости обрабатываются корректно: множество `visited`
не позволяет войти в узел повторно, поэтому обход всегда завершается.
Дополнительно `find_cycle` (DFS со стеком пути) находит цикл и выводит
сообщение вида `Обнаружен цикл: A -> B -> D -> A`.

Допущение: зависимости корневого пакета берутся для заданной версии,
а для транзитивных пакетов — для последней доступной версии.

### Тестовый режим

Вместо URL репозитория указывается путь к файлу описания графа
(`--test-mode`). Формат файла — по одной строке на пакет:

```text
ИМЯ: ЗАВИСИМОСТЬ1 ЗАВИСИМОСТЬ2
```

Имена пакетов — заглавные латинские буквы. Пустые строки пропускаются.
Пример файла:

```text
A: B C
B: D
C: D
D:
```

Ошибки тестового режима: файл не найден, строка без `:`, имя не из
заглавных букв, анализируемый пакет отсутствует в графе.

### Обратные зависимости (этап 4)

Режим `--reverse` выводит пакеты, которые зависят от заданного, — прямо
и транзитивно. Граф обращается (`reverse_graph`), после чего применяется
тот же рекурсивный DFS (`build_graph`), что и на этапе 3.

Режим доступен только с `--test-mode`: репозиторий PyPI не предоставляет
информации о том, какие пакеты зависят от заданного. Используется весь
граф из файла, а не подграф от корня. При отсутствии зависимых пакетов
выводится «отсутствуют».

### Визуализация (этап 5)

Граф выводится в трёх видах:
- текст на языке диаграмм **Graphviz** (`to_dot`) — печатается в консоль;
- **изображение**: DOT сохраняется в `out/<пакет>.dot`, рендерится
  утилитой `dot -Tpng` в `out/<пакет>.png` и открывается системным
  просмотрщиком (`show_image`);
- **ASCII-дерево** — при указании флага `--ascii-tree`; циклы
  помечаются словом «(цикл)» и не разворачиваются бесконечно.

Требуется установленный Graphviz (`dot` в PATH). При его отсутствии
выводится ошибка «Graphviz не установлен: команда dot не найдена»,
код завершения 1. Папка `out/` добавлена в `.gitignore`: сгенерированные
DOT- и PNG-файлы в репозиторий не попадают.

### Сравнение со штатными инструментами

Результаты сравнивались с `pipdeptree` (дерево установленных пакетов)
и `pip show` для пакетов requests, flask и click.

| Расхождение | Причина |
| --- | --- |
| Корень: у нас requests 2.31.0, у pipdeptree 2.34.2 | мы анализируем заданную пользователем версию из PyPI, pipdeptree — установленную в окружении |
| Разные спецификаторы (`urllib3 >=1.21.1` против `>=1.26`) | следствие разных версий корня |
| pipdeptree печатает `installed: 3.5.2`, мы — ограничения версий | он показывает фактические версии, мы — объявленные требования |
| У click 8.1.7 есть colorama и importlib-metadata, у click 8.5.1 в pipdeptree зависимостей нет | разные версии пакета: в новых версиях зависимости удалены |
| У нас есть colorama/importlib-metadata независимо от ОС и версии Python | мы отбрасываем маркеры окружения, pip применяет их к текущей системе |
| В графе flask два узла: `MarkupSafe` и `markupsafe` | PyPI нормализует имена пакетов, мы сравниваем строки как есть |
| Нет опциональных зависимостей | зависимости с `extra == "..."` не учитываются |
| У pipdeptree меньше узлов | он показывает только установленные пакеты, мы — все объявленные в метаданных |

## Сборка и запуск тестов

Сборка не требуется: проект написан на Python и запускается без компиляции.
Внешние зависимости: Graphviz (для рендера изображения), pytest (для тестов).

Запуск (из корня репозитория):

- Linux / macOS: `./run.sh` или `python3 src/main.py`
- Windows: `run.bat` или `py src/main.py`

Запуск тестов (из корня репозитория):

- Linux / macOS: `python3 -m pytest tests/ -v`
- Windows: `py -m pytest tests/ -v`

Демонстрационные скрипты (Windows):

- Демонстрация параметров и ошибок: `./check_config.bat`
- Демонстрация прямых зависимостей: `./check_deps.bat`
- Демонстрация графа и циклов: `./check_graph.bat`
- Демонстрация обратных зависимостей: `./check_reverse.bat`
- Демонстрация визуализации трёх пакетов: `./check_visual.bat`

## Примеры использования

Прямые зависимости пакета:

```text
$ py src/main.py --package requests --repo https://pypi.org --version 2.31.0
package: requests
repo: https://pypi.org
test-mode: выключен
version: 2.31.0
ascii-tree: выключен
reverse: выключен
Прямые зависимости requests 2.31.0:
  charset-normalizer (<4,>=2)
  idna (<4,>=2.5)
  urllib3 (<3,>=1.21.1)
  certifi (>=2017.4.17)
```

Визуализация с ASCII-деревом:

```text
$ py src/main.py --package click --repo https://pypi.org --version 8.1.7 --ascii-tree
ASCII-дерево:
click
|-- colorama
`-- importlib-metadata
    |-- zipp
    `-- lazy-importer
Описание графа на языке Graphviz:
digraph dependencies {
    rankdir=LR;
    "click";
    "click" -> "colorama";
    "click" -> "importlib-metadata";
    ...
}
Изображение графа: out\click.png
```

Тестовый режим (ромб):

```text
$ py src/main.py --package A --repo tests/data/graph.txt --test-mode
A: B C
B: D
C: D
D:
```

Тестовый режим (цикл):

```text
$ py src/main.py --package A --repo tests/data/cycle.txt --test-mode
A: B
B: D
D: A
Обнаружен цикл: A -> B -> D -> A
```

Ошибка формата:

```text
$ py src/main.py --package A --repo tests/data/bad.txt --test-mode
Ошибка: строка 1: имя не заглавные буквы: a
```

Обратные зависимости:

```text
$ py src/main.py --package D --repo tests/data/graph.txt --test-mode --reverse
Обратные зависимости D:
  A
  B
  C
```

Ошибка параметра:

```text
$ py src/main.py --package requests --repo https://pypi.org
Ошибка: в реальном режиме требуется параметр --version
```
